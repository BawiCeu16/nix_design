# Changelog

## 0.0.1

* Initial open-source release of `nix_design`.
* Pure stadium/pill design system for Flutter with theme-reactive components:
  * **Buttons**: `NixButton` (`.filled`, `.tonal`, `.outlined`, `.text`, `.ghost`), `NixIconButton`, `NixButtonGroup`.
  * **Inputs**: `NixSwitch`.
  * **Chips**: `NixChip`, `NixFilterChip`.
  * **Navigation**: `NixSegmentedControl`, `NixTabBar`, `NixBottomBar` (responsive, dynamic equal widths, gesture sliding indicator, unshrink on touch, scroll-to-hide/shrink).
  * **Surfaces**: `NixCard` (`.pill`, `outlined`, `filled`).
  * **Feedback**: `NixSnackBar` (floating stadium pill, dynamic width, slide animations, theme reactive), `NixDialog`, `showNixDialog`.
